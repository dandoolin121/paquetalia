# Paquetalia

Apka do zapisywania paczek w drodze. PWA (React + TypeScript + Vite), dane trzymane lokalnie w telefonie.

```bash
npm install
npm run dev        # serwer deweloperski, tylko na tym komputerze
npm run dev:phone  # to samo, ale widoczne w sieci Wi-Fi – do testów na telefonie; wyłącz po teście
npm run build      # build produkcyjny do dist/
```
